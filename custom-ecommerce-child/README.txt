== Description ==

This child theme inherits all styling, templates, Customizer settings, and WooCommerce functionality from the `custom-ecommerce-theme` parent theme. Place any custom CSS in `style.css`, custom PHP hooks in `functions.php`, or template overrides in matching subdirectories.
